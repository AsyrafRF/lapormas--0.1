## Tentang prototipe

LaporMas! merupakan portal simulasi pelaporan masyarakat di lingkungan perumahan. Prototipe frontend ini menyediakan alur untuk empat peran: Masyarakat, Petugas Keamanan, Admin, dan Ketua RT. Implementasi saat ini menggunakan data simulasi pada browser dan belum terhubung ke backend atau database produksi.

Untuk instalasi dan penggunaan, lihat [README proyek](../README.md) dan [dokumentasi utama](./README.md).
